### Beginner-Layer Checker AI Agent

*Individual Capstone Project | Practical AI for Economic Developers*

**Program by:** Economic Developers Association of Newfoundland and Labrador (EDANL)  
**Training Provider:** Keyin College

I developed an AI-assisted agent to review beginner-level AI and LLM educational materials for technical accuracy, clarity, learning-objective alignment, and content organization.

I designed the prototype using ChatGPT Projects and custom instructions. During testing, the agent identified two intentionally misleading statements in a fictional machine learning handout and suggested corrections.

I also refined its privacy instructions after identifying unnecessary organization references in the review output.

This project involved AI agent design, prompt engineering, content evaluation, testing, and responsible AI practices.
